# Harbor Master

The example app for `harbor`: a small harbor game whose scenes use every pattern the package
supports, plus the **Harbor Field Guide**, which has one page per class on a pretend phone.

- `SCENARIOS.md` lists each scene, the pattern it demonstrates and the file it lives in.
- `fvm flutter run` starts the game. `fvm flutter run -t lib/field_guide_main.dart` opens the
  field guide on its own.
- `fvm flutter test` runs the scene and field-guide widget tests.
- The device play-through, and how to sign the app for a real phone, are in the package
  `README.md` under **Example**.
